# Project Ascension – Regulatory Operations Watchtower

## Overview

Project Ascension is an AI Operations portfolio project demonstrating how AI agents and workflow automation can monitor regulatory developments, analyze changes using LLMs, assess business risk, and notify stakeholders automatically.

## Objective

Build an AI-powered regulatory intelligence platform capable of:

- Monitoring regulatory sources
- Summarizing new publications using AI
- Classifying regulatory risk
- Sending alerts via Telegram
- Maintaining an auditable knowledge base

## Technology Stack

- n8n
- OpenAI / Claude
- Git & GitHub
- Telegram Bot API
- RSS / Web APIs
